# PrincessPower
🌸 Meiteņu sporta grupu un tiešsaistes treniņu atrašanas rīks Latvijā. Piesakies, uzzini padomus un kusties droši!
Vienkārša programma, kas palīdz meitenēm atrast sporta grupas, kur justies droši un pieteikties treniņiem. Ietver arī skaistumkopšanas padomus un tiešsaistes treniņu saites.

<h3>Kā lietot</h3>
1. Atver programmu (nepieciešams Python 3).
2. Izvēlies pilsētu un aktivitātes veidu.
3. Spied **"❤️ Parādi draudzīgās grupas"**.
4. Rezultātos noklikšķini uz interesējošās grupas – atvērsies detalizēts logs.
5. Detalizētajā logā vari redzēt aprakstu, ko ņemt līdzi, jau pieteikušos dalībnieces, un pieteikties, ievadot savu vārdu.
6. Izmanto pogu **"💄 Skaistuma padomi"**, lai saņemtu rotējošus ieteikumus.
7. Ja vēlies atvērt tiešsaistes treniņa saiti, spied **"💻 Tiešsaistes treniņš"**.

<h3>Datu atjaunināšana</h3>
- Atver `grupas.csv` ar Excel vai Notepad.
- Pievieno jaunu rindu ar nepieciešamajām kolonnām: `pilseta,tips,nosaukums,vieta_laiks,kontaktinformācija,tiessaiste,apraksts,lidzi`.
- Saglabā un palaid programmu no jauna.

<h3>Faili</h3>
- `princesspower.py` – galvenais kods.
- `grupas.csv` – sporta grupu datubāze.
- `padomi.txt` – skaistuma padomi (katrs padoms jaunā rindā).
- `pieteikumi.csv` – automātiski izveidots, glabā pieteikumus.
